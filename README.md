## 📖 项目简介

**NorthClass** 是一家拥有 100+ 门课程、约 30 万注册学习者的高等教育培训机构。为评估教学效果、优化教学资源，机构收集了学习者完整的时序学习行为数据，并期望借助**可视化与可视分析技术**，将复杂的时序学习行为数据转化为图形表达，帮助诊断学习者的知识掌握水平、动态追踪学习行为演变、识别学习过程中的潜在问题。

本项目针对以下五个任务提出了一套完整的可视分析解决方案：

1. **知识点掌握评估** —— 从答题分数、答题状态等多维度属性量化评估知识点掌握程度，识别知识体系中的薄弱环节；
2. **学习者画像** —— 结合学习者特征挖掘个性化学习行为模式，多角度展示答题高峰时段、偏好题型、正确答题率等；
3. **学习模式建模** —— 对学习模式与知识掌握程度之间的潜在关系进行建模，利用图表呈现结果并简要分析；
4. **不合理题目识别** —— 利用可视分析方法找出"知识掌握水平很高但答题正确率较低"的不合理题目；
5. **教学优化建议** —— 结合上述分析结果，为题目设计者和课程管理人员提供优化建议。

## 📊 数据集

赛题提供了 **15 个班级**从 2023 年 8 月 31 日到 2024 年 1 月 25 日共 **148 天**的学习行为模拟数据：

| 数据文件 | 规模 | 字段说明 |
|----------|------|----------|
| 学习者基本信息 | 1364 名 | `student_ID`（唯一编码）、`sex`、`age`、`major` |
| 题目基本信息 | 44 条 | `title_ID`（唯一编码）、`score`、`knowledge`、`sub_knowledge` |
| 答题行为日志 | 232,818 条 | `class`、`time`、`state`、`score`、`title_ID`、`method`（编程语言）、`memory`、`timeconsume`、`student_ID` |

> 📌 一个题目可能考察多个知识点，一个知识点也可能有多个从属知识点，存在多对多关系。

## 🧹 数据预处理

- **缺失值检查**：三个数据集均无缺失值；
- **异常时间值**：`timeconsume` 列存在 `'-'` 字符数据共 2612 条，其对应分数几乎全为 0（代码运行超时或报错所致），予以保留；仅删除 1 条 `timeconsume='-'` 但分数不为 0 的异常记录；
- **内存异常**：`memory=0` 共 52635 条，但得分均为 0，属正常现象，不影响分析；
- **无效学生编号**：发现 1 条学生 id 多了末尾字符 `D` 的记录，判定为输入错误，已修正；
- **无效班级记录**：6 条班级字段异常但学生 id 正确的记录，因后续不依赖班级信息，予以保留；
- **异常答题状态**：`state` 本应只有 12 种取值，实际多出 Error1~Error9 共 6 条异常记录，已删除，并将 Error 类统一记为 `error`；
- **时间格式转换**：将 `time` 列的 Unix 时间戳转换为真实时间。

### 知识体系结构

题目 id 存在重复记录（44 条数据 → **38 个不重复题目**），对应 **8 个知识点**、**15 个从属知识点**。基于 `pyvis` + `networkx` 构建了知识点-从属知识点-题目的三层**交互式网络结构图**：

- 🔵 蓝色节点 = 知识点
- 🟢 绿色节点 = 从属知识点
- 🔴 红色节点 = 题目

支持鼠标拖动节点、调节位置，便于分析三者之间的关联关系。

## ✅ 任务解决方案

### 任务一：知识点掌握程度量化评估

以知识点和从属知识点为主提取 **16 维指标**：题目总分、题目总目、得分率、完全正确数目、部分正确数目、错误数目、各编程语言使用次数、内存大小、运行时间、完全正确率、部分正确率、总正确率（含最后一天的得分率）等。

- **平行坐标图**：16 个维度分三组指标绘制，每个轴显示真实取值（整数数据向下取整、小数保留三位），右侧颜色映射表区分各知识点/从属知识点，支持 B 样条平滑曲线；
- **雷达图**：保留完全正确数、正确率等大数值指标（剔除内存、错误数目等），面积越大代表掌握越好；
- **折柱混合图**：以知识点为横轴，柱状图表示完全正确率/部分正确率/总正确率，折线表示得分率——**柱状高度和折线点不匹配的知识点即薄弱环节**。

支持输入学生 id 查询单个学习者情况（额外展示最后一天的得分率数据）。

### 任务二：学习者画像

提取全部 135 名学习者的行为数据，多角度构建画像：

| 可视化 | 呈现内容 |
|--------|----------|
| **热力图** | 周内每小时做题数目分布（答题高峰时段），每个格子显示具体数值，支持选择单天或单个时段查看 |
| **旭日图** | 从中心向外辐射的多个环形层次：知识点 → 从属知识点 → 各层次比例，扇区大小随做题数目调整，点击可展开下钻 |
| **条形图** | 各题目的正确答题率横向对比，比率差距直观清晰 |

### 任务三：学习模式与知识掌握建模

将学习模式数据与知识掌握数据合并后，采用 **5 种回归算法**建模（80/20 训练测试集划分），以总体得分和总正确率为预测目标，MSE 和 R² 作为评估指标：

1. 线性回归（OLS）
2. 随机森林回归
3. 梯度提升回归
4. XGBoost 回归
5. CatBoost 回归

**关键发现：**

- 🌙 **线性回归**显示：晚上的做题时间与做题数最为重要——晚间思路清晰、做题正确率有所提高，符合常规认知；
- 🔢 **随机森林 / 梯度提升**显示：总做题数十分重要，编程语言 `Method_LBXr9AiSpQhwNvyGdZL57` 也占据一定比重，使用该方法答题更高效简单；
- 📊 利用**特征重要性条形图**和**跨模型特征重要性热力图**对比各模型的特征权重；
- 🔍 使用 **SHAP 值**（基于 Shapley 值的博弈论解释方法）解释最佳模型（随机森林）的预测贡献。

### 任务四：不合理题目识别

采用**桑基图**呈现知识点 → 从属知识点 → 题目的层级流动关系，并添加颜色映射：**蓝色代表正确率低，红色代表正确率高**。若知识点/从属知识点节点颜色较深（掌握好）而对应题目节点颜色较浅（正确率低），即说明该题目难度超出学习者能力范围，为不合理题目。

支持切换展示全部正确率 / 部分正确率 / 总体正确率，也可输入学生 id 查看个体情况。

### 任务五：教学优化建议

1. **加强基础知识点的覆盖**——通过特征重要性分析和可视化手段识别对学生总成绩和正确率影响最大的知识点，针对得分很低的知识点增加基础题型层递进，优化题库覆盖；
2. **增加多样化的题型**——题库中增加选择、填空、简答和应用型题目，多方面评估知识掌握情况；解答题解题时间长，选择填空类可利用碎片时间巩固知识点；
3. **针对薄弱环节设计专项练习**——根据分析结果中识别出的薄弱知识点，设计针对性的专项练习和复习材料；
4. **定期更新和优化题库**——根据学生反馈和考试结果定期更新题库内容，确保题目难度适中、覆盖全面；
5. **提供个性化学习路径**——根据每个学生的学习情况和成绩表现探寻学习模式，找出不合理之处加以改进，提供个性化学习建议和复习路径。

## 📈 核心方法原理

### 平行坐标图 B 样条平滑

突破常规直线绘制方式，采用 **B 样条（B-Spline）曲线**绘制平滑折线。B 样条基函数由局部支持且线性无关的多项式函数构成，递归定义如下：

$$N_{i,0}(t) = \begin{cases} 1 & \text{if } t_i \le t < t_{i+1} \\ 0 & \text{otherwise} \end{cases}$$

$$N_{i,k}(t) = \frac{t-t_i}{t_{i+k}-t_i}N_{i,k-1}(t) + \frac{t_{i+k+1}-t}{t_{i+k+1}-t_{i+1}}N_{i+1,k-1}(t)$$

样条函数 $S(t) = \sum_{i=0}^{m} c_i N_{i,k}(t)$，其中 $c_i$ 为控制点权重。结合颜色映射、数据归一化、类别数据编码，生成高度定制化的多维可视化。

### 回归模型评估指标

**均方误差（MSE）** 衡量预测值与真实值之间差异的平方均值：

$$MSE = \frac{1}{n}\sum_{i=1}^{n}(y_i - \hat{y}_i)^2$$

**R² 分数（决定系数）** 衡量模型解释变量变异能力的比例：

$$R^2 = 1 - \frac{\sum_{i=1}^{n}(y_i - \hat{y}_i)^2}{\sum_{i=1}^{n}(y_i - \bar{y})^2}$$
